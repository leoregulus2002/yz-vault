# Changelog

All notable changes to this project are documented here.

## [0.1.0-SNAPSHOT] - 2026-09-22

### Added

- Java 26 / Spring Boot 4 Maven multi-module architecture skeleton.
- Framework-free identifier and Lease lifecycle models.
- Shared API response and error contracts.
- Plugin contracts for secret engines, cryptography, storage, authentication, database plugins, and auditing.
- Spring Boot server bootstrap, architecture documentation, and ADR-0001.
